A simple video content factory for organizing early-stage content ideas and
drafts. The initial release is a small, reliable web application with a clear
browser UI, API, and database foundation; advanced agentic workflow automation
and visual/video asset creation are deferred to a future sprint.

Web App. Use Bootstrap for the frontend and FastAPI+SQLite for the backend.
Start with a small set of applications and companies as seed data.

Initial capabilities:

1. Browse and manage the seeded applications and companies.
2. Capture content projects, optionally associated with an application and a
   company.
3. Create and store a simple draft script or prompt for each content project.
